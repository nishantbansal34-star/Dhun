# Dhun 🎵

One app for your own music files **and** YouTube.

- **My Music** — every song on your phone, by song / album / artist, search, play, shuffle, repeat, "play next". Keeps playing in the background with lock-screen and notification controls.
- **YouTube** — search YouTube for any song (needs a free YouTube Data API key), or paste/share any YouTube or YT Music link into Dhun. Auto-plays the next result. Save tracks you like.
- **Playlists** — Liked songs plus your own playlists.

YouTube plays through YouTube's official embedded player, so the video stays on screen and pauses when you leave the app — that's YouTube's rule for third-party apps.

## Install
Every push to `main` builds the APK automatically. Open **Releases → latest** on your phone, download `Dhun.apk`, and install. New builds install as updates.
